# Alerta Golpe

Protótipo em Python que estima a chance de uma mensagem (SMS ou WhatsApp) ser golpe
financeiro, mostra os sinais que mais pesaram e dá uma dica de segurança em linguagem
simples. O público são pessoas idosas e quem as ajuda.

Projeto em construção. O README completo, com os resultados medidos, vem ao final.

## Como rodar localmente

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
pytest
```
